# Design System — Documentation et CLI

DESIGN_SYSTEM: PASS

Produit documentaire, sans interface graphique : couleurs, tokens visuels,
responsive et composants UI sans objet. Markdown lisible, tableaux courts pour
mappings, liens relatifs pour documents livrés. Un document canonique par règle.
Titres explicites ; erreurs CLI non nulles, refus sans écrasement, état de
présence distinct d'un verdict de gate. Aucun rendu graphique à tester.

Verdict : PASS
