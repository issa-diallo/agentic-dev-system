# Design — #6

DESIGN: PASS, après Research PASS.

## Contrat observable
AGENTS conserve gates, DoR/DoD, sécurité, Gitmoji, isolation et stack. Le lecteur
ouvre README de méthode puis seulement les sources applicables, sans rendre
une obligation optionnelle. Sources de vérité ordonnées en cas de conflit.
MODÈLES : cinq niveaux recommandés, sélection disponible et fallback honnête.
CONTEXTE : recherche ciblée, résumé de transition, mesures et matrice 01–26.
RÔLES : les trois actuels suffisent, spécialités attachées au périmètre.
PLAN contient complexité et contrat, HANDOFF sert aussi de checkpoint.

## Installation
Mêmes arguments et protections ; aucune activation tierce, aucune stack imposée.
Nouveaux docs automatiquement copiés. STATUS neuf vient d'un template neutre,
work exclu ; produit du dépôt source jamais copié à la place des templates.
Personnalisation par docs projet et AGENTS de sous-dossiers, pas écrasement.
Liens du socle résolus en PRODUCT/EXISTING/LOCAL ; emplacements futurs décrits
comme chemins, pas comme liens prétendant exister.

## Erreurs et validation
Refus de source incomplète avant écriture ; checker incomplet retourne non zéro.
Conserver collisions/symlinks et LOCAL. Sans UI : mêmes conventions Markdown/CLI
que DESIGN_SYSTEM. Sans outil optionnel : fonctionnement normal, testé.

Verdict : PASS
